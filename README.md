# 12 Sprint Mission FE

> Codeit Sprint FS 12기 Mini Project  
> 판다마켓 프로젝트

---

## 📌 프로젝트 이름
**판다 마켓**

---

## 📖 프로젝트 소개
Codeit Sprint FS 12기 과정 중 진행한 스프린트 미션(프론트엔드 파트) 프로젝트입니다.

HTML과 CSS를 활용하여 다중 페이지 구조의 정적 웹사이트를 구현하였으며,  
페이지별 스타일을 분리하여 유지보수를 고려한 구조로 설계하였습니다.  

Git과 GitHub를 활용하여 브랜치 기반 전략을 경험하였습니다.

---

## 🛠 사용 기술
- HTML
- CSS
- Git
- GitHub

---

## 📂 페이지 구성

| 파일명 | 설명 |
|--------|----------------|
| `index.html` | 메인 페이지 |
| `login.html` | 로그인 페이지 |
| `signup.html` | 회원가입 페이지 |
| `items.html` | 상품 목록 페이지 |
| `faq.html` | 자주 묻는 질문 페이지 |
| `privacy.html` | 개인정보 처리방침 페이지 |
